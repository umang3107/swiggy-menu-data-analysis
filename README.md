# Swiggy Menu Data Analysis

## Project Overview
This project analyzes menu data from popular restaurant chains in Nashik using Swiggy APIs. Data was collected through Browser Developer Tools, cleaned in Excel, and analyzed using SQL.

## Objectives
- Collect restaurant and menu data from Swiggy APIs
- Create a structured dataset
- Analyze pricing patterns across restaurants
- Identify highest and lowest priced items
- Compare restaurant pricing strategies

## Tools Used
- Browser DevTools
- SQL
- Microsoft Excel

## Dataset Columns
- Restaurant Name
- Menu Category
- Item Name
- Price

## Analysis Performed
- Highest priced item by restaurant
- Lowest priced item by restaurant
- Price comparison across restaurants
- Restaurant pricing strategy analysis

## Key Findings
- Barbeque Nation had the highest priced item (₹999)
- Burger King had the lowest priced item (₹70)
- Premium restaurants focus on combo meals and family packs
- Fast-food chains compete through affordable entry-level products
